Ai Best Fun Uploader Privacy Policy

Last updated: May 26, 2026

Overview

Ai Best Fun Uploader is a private tool used to manage uploads for the official Ai Best Fun TikTok account. The tool is not a public consumer application.

Data Used

The tool may use TikTok account authorization data, basic profile information returned by TikTok, video upload status, local video file names, captions, hashtags, and publishing links.

How Data Is Stored

Access tokens and publishing records are stored locally on the account owner's computer. They are used only to authenticate API requests and track upload status.

How Data Is Shared

The tool sends selected video files, captions, and upload metadata to TikTok when the account owner starts an upload. Data is not sold or shared with third parties for advertising.

Data Retention

Local publishing records may be kept as long as needed to avoid duplicate uploads and maintain the channel archive. Tokens can be deleted locally at any time.
